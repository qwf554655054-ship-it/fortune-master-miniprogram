# M7 · 商业化与上线方案（命理测算小程序）

> 面向对象：非技术背景的创始人（学友）。本文用大白话讲清楚「怎么赚钱」和「怎么上线」，并把需要你拍板 / 跑腿的事项单独列出。

---

## 一、产品现状（一句话）

我们已经做出一个**可运行的命理测算应用**，包含 **13 个测算体系**（八字、紫微、生肖、日运、数秘、塔罗、六爻、奇门、风水、合盘、年运、月运、西方星盘），前端有 Web 版 + 微信小程序壳，后端零额外依赖、可离线跑。本次 M7 在它基础上补齐了**会员/付费**的雏形与上线路径。

---

## 二、商业化模型（推荐：Freemium 免费增值）

### 核心思路
- **免费**：13 个体系的「基础解读」全部免费，吸引流量、沉淀用户。
- **付费（会员）**：解锁每个体系的「💎 会员专享·深度延展」——更贴合个人、更具行动指引的进阶内容。

### 为什么是会员而不是单次售卖？
命理类 App 用户黏性来自「反复测、长期看」，会员订阅（月/年）比单次付费更稳、ARPU 更高，也更符合微信/苹果的内购规则。

### 建议定价（参考市面同类，可随时调）
| 套餐 | 价格 | 说明 |
|------|------|------|
| 月度会员 | ¥19.9 / 月 | 低门槛体验 |
| 年度会员 | ¥199 / 年 | 相当于月费的 8.3 折，主推 |

> 价格只是占位建议，最终由你根据竞品与投放成本决定。

### 代码里已落地的部分（当前为「演示态」）
- 后端 `store.js` 按用户（`X-Client-Id`）存会员状态；`/api/membership` 查状态、`/api/membership/upgrade` 模拟开通。
- `/api/reading` 支持 `deep:true`，**仅会员可调用**，否则返回 403（已在测试中断言）。
- 解读层 `interpreter.js` 已为每个体系写了一段「深度延展」内容，会员调用即返回。
- Web 端「会员」Tab、小程序「会员」页均已接入，可演示开通→解锁深读的完整闭环。

⚠️ **当前未接真实支付**：开通是本地模拟、`demo:true` 标记。上线前需替换为微信支付（小程序）或苹果内购（iOS）。

## 三、合规红线（务必先看，命理类最容易被下架）

我们已在 M6 落地了**娱乐声明 + 未成年人保护 + 内容安全**。商业化时还要守住三条铁律：

1. **绝不「付费改运 / 消灾 / 转运」**：这是诈骗高发区，也是平台重点打击项。我们的免责声明已明确「不提供任何付费改运服务」。
2. **定性为「娱乐/工具」，不碰医疗、法律、财务建议**：所有解读结尾都有娱乐声明。
3. **微信类目资质**：小程序「算命/占卜/风水」类目审核极严，通常需要《增值电信业务经营许可证》（ICP 证）等资质，且平台保留拒绝权利。**详见下方「上线清单」**。

---

## 四、上线路线图（分三步，风险从低到高）

### 步骤 1：先跑通 Web 版（最快验证，1 天内）
- 本地 `node server.js` 即可访问；部署到静态/容器托管后即可分享链接测真实用户反应。
- 见同目录 `DEPLOY.md`。

### 步骤 2：小程序内测（微信「体验版」）
- 微信开发者工具导入 `miniprogram/`，填你的真实 AppID，`apiBase` 指向你的后端 HTTPS 地址。
- 先发「体验版」给少量好友内测，**不要急着走正式类目审核**。

### 步骤 3：正式商业化上线（需资质 + 接支付）
1. 办理 ICP 备案 +（如需）增值电信业务经营许可证；
2. 申请微信支付商户号，把 `/api/membership/upgrade` 接到真实下单；
3. iOS 端若上架 App Store，须用苹果内购（IAP），不能用微信支付绕开；
4. 提交类目审核，配齐《隐私政策》《用户协议》。

## 六、风险提示（诚实告知）

- 命理/占卜类在主流平台（微信、苹果、各应用商店）均属于**敏感类目**，存在被拒审、下架、支付接口被关停的风险。**不要把全部营收押注在单一平台**，Web 版 + 私域是更稳的兜底。
- 真实支付与资质务必齐全，**切勿在未持证情况下以「改运」收费**，否则有法律与封号风险。
