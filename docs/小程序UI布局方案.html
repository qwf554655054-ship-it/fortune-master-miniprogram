命理测算小程序 · 整体 UI 布局方案

目标：在沿用现有「玄学暗色风（深棕底 + 金色点缀）」的前提下，优化信息架构与操作路径。以下提供 4 个方案，请选择其一作为下一版 UI 方向。

现状小结（来自 app.json / index.wxml）：底部 3 个 Tab = 测算 / 我的 / 会员（纯文字、无图标）；测算首页是「一行标语 + 平铺的体系名称宫格（八字/紫微/塔罗…全部等权重）+ 免责声明」，没有主按钮、没有个性化、没有日活内容；「会员」作为一级 Tab 位子偏重，「我的」页同时塞了记录/设置/关于。核心问题：体系入口无重点、缺乏留存钩子、会员与记录职责混淆。

布局结构

底部 4 Tab：测算 / 运势 / 记录 / 我的。测算首页 = 顶部问候 + 金色主 CTA 卡「立即测算」+「常用体系」宫格（P0 八字/紫微高亮）+「最近测算」历史卡。

信息层级与视觉动线

  • 一级：4 个底部 Tab（全局导航）。
  • 二级：首页把「所有入口」聚合在一屏，视线动线：问候 → 大 CTA → 体系宫格 → 历史。
  • 三级：各体系结果页（卡片化渲染 AI 解读）。

适用核心场景

日常测算复访、老用户回看历史；新用户首屏即知「点哪里开始」。

相比现状的主要改进

  • 新增「运势」Tab承载生肖月运/每日一签等轻量内容，提升日活与留存。
  • 会员降为「我的」内二级，Tab 从 3 变 4 但职责更清晰（会员是低频转化，不该占满一级位）。
  • 首页从「平铺宫格」变为有重点的卡片流，P0 体系高亮，首屏出现明确主按钮。

布局结构

底部 3 Tab：测算 / 记录 / 我的。测算首页 = 占上半屏的 Hero 大区（命盘概览 + 超大「开始测算」按钮）+ 横向滑动体系胶囊 + 一句运势格言。

信息层级与视觉动线

  • 全屏只服务一件事：引导用户点击「开始测算」。
  • 体系用横向胶囊（单手拇指可达），替代宫格，节省纵向空间。
  • 动线极短：打开 → 点大按钮 → 选体系 → 出结果。

适用核心场景

投放拉新、活动落地页、付费转化导向；新用户无需思考「点哪」。

相比现状的主要改进

  • 消除首页信息过载，单一主行动CTA 显著提升点击率。
  • 体系入口改为横向胶囊，单手操作更顺、信息密度可控。
  • 会员/设置等低频功能全部收进「我的」，首屏零干扰。

布局结构

顶部可滑动分类标签（全部/八字/紫微/塔罗/星盘/生肖/关系…），左上角汉堡菜单唤出侧边抽屉收纳全局功能（测算/记录/我的/会员/设置/关于）；主体为「信息流卡片」。

信息层级与视觉动线

  • 顶部分类 = 一级切换（像资讯 App 频道）。
  • 侧边抽屉 = 低频全局入口，首页保持纯净。
  • 动线：选分类 → 滑卡片流 → 点卡片看详情；全局功能走抽屉。

适用核心场景

体系数量膨胀到 10+ 后、希望用户「逛」内容的成熟期；适合做运势日报/专题流。

相比现状的主要改进

  • 体系再多也不挤首页，顶部分类切换比宫格更 scalable。
  • 侧边抽屉把会员/设置/关于等低频项彻底挪走，首页零冗余。
  • 信息流形态天然适合沉淀「每日一签/生肖运」等留存内容。

布局结构

底部 4 Tab：首页 / 运势 / 记录 / 我的；右下角常驻金色悬浮球「测」，任何页面一点即弹出半屏选体系。首页以内容（今日运势大卡）为主、体系入口次之。

信息层级与视觉动线

  • Tab 负责「内容浏览」，FAB 负责「核心动作」，职责分离。
  • 动线：看内容（首页/运势）→ 想测了 → 右下角 FAB 一步直达，无需回首页。
  • FAB 避让底部 Tab 与内容，小屏需留 16px 安全边距。

适用核心场景

高频「随时想测一下」的用户；内容消费 + 即时测算并重的成熟期产品。

相比现状的主要改进

  • 核心动作「测算」常驻可达，把现状「回首页→点宫格」的两步压缩成一步。
  • 首页首屏给「今日运势」内容钩子，承接方案 A 的留存思路。
  • 会员移入「我的」，Tab 结构更干净。

我的建议：若马上要做下一版，选 方案 A——它最稳、最贴小程序惯例、且一次性解决了现状三大痛点（无重点、无留存钩子、会员/记录混淆）。等体系数量膨胀到 10+ 或进入高频测算阶段，再平滑演进到 方案 C / D。方案 B 适合作为「拉新活动落地页」单独存在，不必做进主框架。四者均沿用现有暗色玄学风（深棕底 + 金色），仅需补 Tab 图标、统一圆角与间距规范，即可保证各页面一致性，并用 rpx + 安全区适配主流机型。
